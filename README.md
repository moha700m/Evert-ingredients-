# Arabic Telegram Store Bot

بوت متجر عربي على Telegram + Vercel يقرأ منتجات Canboso/CipherForge، ويعرض تفاصيل المورد الأصلية ويدعم الدفع عبر Telegram Stars داخل محادثة البوت.

التصفح عبر أزرار Telegram، وبيانات الحساب عبر ForceReply. المنتجات التي تحتاج بريدًا تدعم حسابًا واحدًا أو حسابين أو ثلاثة، بفواتير وطلبات مستقلة بكمية واحدة لكل حساب. الصفحة الرئيسية رابط لفتح البوت؛ لوحة الإدارة الحالية محفوظة.

## النشر

- الأسرار تحفظ في Vercel Environment Variables فقط.
- ابدأ مع `ENABLE_LIVE_PURCHASES=false`.
- بعد إضافة أو تعديل Environment Variables في Vercel، نفّذ Redeploy للإنتاج حتى تُحمّل القيم الجديدة.
- بعد النشر نفّذ `/api/setup?secret=YOUR_SETUP_SECRET` لربط Webhook.
- افحص `/api/debug-products?secret=YOUR_SETUP_SECRET` قبل تفعيل البيع الحقيقي.
- `/api/health` يفحص حالة البوت والـWebhook دون تغييرهما. الإصلاح اليدوي يتطلب `repair=1` ومفتاح `SETUP_SECRET` و`PUBLIC_BASE_URL` الصحيح.

## الفحوصات

- `npm run check` لفحص صياغة ملفات JavaScript.
- `npm test` لاختبارات المورد وTelegram والدفع باستخدام بيانات وهمية، دون شراء حقيقي.

## متغيرات أساسية

راجع `.env.example` لكل الإعدادات المطلوبة.

## الأمان

لا تضع Bot Token أو API Key في GitHub. يتحقق البوت من السعر والمخزون قبل قبول الدفع، ويستخدم معرّف دفعة Telegram لمفتاح عدم تكرار طلب المورد. عند رفض مؤكد من المورد، يحاول `refundStarPayment` تلقائيًا، وينبّه الإدارة إذا فشل الاسترجاع.

إذا كانت نتيجة المورد غير مؤكدة بعد انقطاع الشبكة، أو تغيّر المنتج بعد الدفع، تُرفع الحالة للإدارة للمطابقة بدل استرجاع دفعة قد يكون طلبها نُفّذ. الحالة المؤقتة داخل الخادم تمنع تكرار التنفيذ في العملية نفسها؛ المطابقة الآلية بين عمليات Vercel الجديدة تحتاج سجل طلبات دائمًا أو استعلامًا من المورد بمفتاح عدم التكرار، وهما غير موجودين في المشروع الحالي.
